A chat agent that remembers when, and checks itself.

minimi bot searches the web, cites every price with its source and date, remembers what you asked and when, re-checks its own past answers, and opens a new chat with one line only when something you asked about has changed. Every number on this page comes from a test run's own output.

    How it works

    Security

    • No keys in the browser. API keys live in the server's environment; the page talks only to its own server.
    • Cross-site requests refused. A POST from another origin, or without a JSON body, gets 403 or 415, so another site cannot spend the budget or move the demo clock.
    • SSRF-safe logo proxy. Site logos are fetched by the server over https from public addresses only (checked at connect time), size and time capped, sniffed as images and served with a strict content policy; otherwise a letter tile.
    • Web text is data. Search results that say "ignore previous instructions" are ignored and tag-like text is defanged; the live run tested it ("prompt-injection-in-results").
    • Safe rendering. The markdown renderer escapes every character before adding its own tags; links must be http(s).
    • Spend cap. A usage meter stops live work at MAX_SPEND_USD (default $5).
